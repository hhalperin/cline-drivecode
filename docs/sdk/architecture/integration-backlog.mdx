## Contributor note — VS Code SDK tests (BL-5.12 / BL-7.8)

- `bun run --cwd apps/vscode test:vitest` — vitest suites under `src/sdk/**` (e.g. `cline-session-factory.test.ts`, `hooks-adapter.test.ts`).
- `bun run --cwd apps/vscode test:unit` — bun:test files only (`run-bun-unit-tests.ts` skips vitest imports).
- CI (`ext-vscode-test`) runs both.
